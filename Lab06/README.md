### Задание 1 **(2)**

Проверить четыре способа объявления `Pi` и определить, где создаётся константа этапа трансляции.

#### Решение

```cpp
#include <cmath>

double x = 0;

const auto Pi1 = std::acos(0) * 2;
constexpr auto Pi2 = std::acos(0) * 2;
const auto Pi3 = std::acos(x) * 2;
constexpr auto Pi4 = std::acos(x) * 2;
```

- `Pi1` — константный объект. В C++20 вызов `std::acos` ещё не является `constexpr`, поэтому значение вычисляется во время выполнения.
- `Pi2` не компилируется в C++20: инициализатор `constexpr` обязан быть константным выражением, а `std::acos` стал `constexpr` только в C++26.
- `Pi3` — константный объект времени выполнения. Дополнительно результат зависит от обычной переменной `x`.
- `Pi4` не компилируется: и вызов `std::acos`, и чтение неконстантной `x` не подходят для константного выражения.

В C++26 второй вариант может стать корректным благодаря `constexpr std::acos`. Четвёртый всё равно останется ошибочным из-за `x`.

### Задание 2

Нужны ли вложенные фигурные скобки в программе, дважды объявляющей `x` и `y` сначала как `int`, затем как `double`?

#### Решение

Да, при сохранении одинаковых имён скобки нужны. Каждый блок создаёт собственную область видимости. После выхода из первого блока целочисленные `x` и `y` уничтожаются, 
поэтому во втором блоке допустимо объявить новые переменные с теми же именами и типом `double`.

Если убрать оба внутренних блока, два объявления окажутся в одной области видимости, а повторное объявление `x` и `y` с другим типом вызовет ошибку компиляции. 
Скобки можно убрать только вместе с переименованием второй пары переменных либо с вынесением вычислений в отдельные функции.

**Код программы (задание 2):**

```cpp
#include <iostream>

int main() {
    {
        int x, y;
        std::cin >> x >> y;
        std::cout << x + y << '\\n';
    }
    {
        double x, y;
        std::cin >> x >> y;
        std::cout << x + y << '\\n';
    }
}
```

### Задание 3

Объяснить результат программы C++ с вложенными циклами, в которых обе переменные названы `i`.

#### Решение

Во внутреннем цикле объявляется новая `i`, которая временно скрывает внешнюю. На каждой из четырёх итераций внешнего цикла внутренний цикл добавляет `0 + 1 + 2 = 3`. 
После завершения внутреннего блока снова видна внешняя `i`, поэтому дополнительно прибавляются `0`, `1`, `2`, `3`.

```text
4 * (0 + 1 + 2) + (0 + 1 + 2 + 3) = 4 * 3 + 6 = 18
```

Ответ программы: `18`.

**Код C++ (задание 3):**

```cpp
#include <iostream>

int main() {
    int s = 0;
    for (int i = 0; i < 4; i++) {
        for (int i = 0; i < 3; i++) {
            s += i;
        }
        s += i;
    }
    std::cout << s << '\\n'; // 18
}
```

### Задание 4

Объяснить результат аналогичной программы Python и сравнить его с C++.

#### Решение

В Python цикл `for` не создаёт отдельной области видимости. Внутренний цикл использует ту же переменную `i` и после каждого своего завершения оставляет в ней значение `2`. 
Поэтому на каждой из четырёх итераций прибавляется `0 + 1 + 2`, а затем ещё `2`.

```text
4 * ((0 + 1 + 2) + 2) = 4 * 5 = 20
```

Ответ программы: `20`. В C++ переменная внутреннего цикла скрывает внешнюю только внутри своего блока; в Python имя внутреннего цикла переназначает то же имя в области видимости функции или модуля.

**Код Python (задание 4):**

```python
s = 0
for i in range(4):
    for i in range(3):
        s += i
    s += i
print(s)  # 20
```

### Задание 5

Создать программу C++, использующую не менее двух пространств имён.

#### Решение

В программе ниже определены пространства `circle` и `square`. В каждом есть функция `area`, но конфликтов нет, поскольку полные имена различаются: `circle::area` и `square::area`.
 Это показывает основное назначение пространств имён — группировку сущностей и предотвращение конфликтов имён.
```cpp
#include <iostream>

namespace circle {
constexpr double pi = 3.141592653589793;
double area(double radius) { return pi * radius * radius; }
}

namespace square {
double area(double side) { return side * side; }
}

int main() {
    std::cout << "Circle: " << circle::area(2.0) << '\n';
    std::cout << "Square: " << square::area(2.0) << '\n';
}
```

### Задание 6 **(2)**

Сравнить обмен двух длинных строк через временную строку и через `swap`, объяснить ошибку и ускорить исходный вариант без изменения его общего вида.

#### Решение

Исходная версия трижды копирует содержимое строк:

```cpp
std::string c(a);
a = b;
b = c;
```

Каждое копирование имеет сложность `O(L)`, где `L` — длина строки. При миллионе повторов это приводит к огромному объёму копирования. `std::swap(a, b)` 
меняет внутренние ресурсы строк и обычно работает за `O(1)`.

Исправление с сохранением временной переменной и присваиваний использует перемещение:

```cpp
std::string c(std::move(a));
a = std::move(b);
b = std::move(c);
```

После перемещения источник остаётся корректным, но его значение не определено; в данном алгоритме ему сразу присваивается следующее значение. Для сравнения всех трёх вариантов можно использовать приведённый ниже код.
 Точные времена зависят от компилятора, оптимизации и компьютера, но копирующая версия должна быть существенно медленнее.


**Программа для измерения времени (задание 6):**

```cpp
#include <chrono>
#include <iostream>
#include <string>
#include <utility>

int main() {
    constexpr int repetitions = 1000000;
    const std::string initialA(100000, 'a');
    const std::string initialB(100000, 'b');

    auto test = [&](int mode) {
        std::string a = initialA;
        std::string b = initialB;
        const auto start = std::chrono::steady_clock::now();
        for (int i = 0; i < repetitions; ++i) {
            if (mode == 0) {
                std::string c(a);
                a = b;
                b = c;
            } else if (mode == 1) {
                a.swap(b);
            } else {
                std::string c(std::move(a));
                a = std::move(b);
                b = std::move(c);
            }
        }
        const auto finish = std::chrono::steady_clock::now();
        std::cout << mode << ": "
                  << std::chrono::duration<double>(finish - start).count()
                  << " seconds, a[0]=" << a[0] << '\\n';
    };

    test(0); // Копирование
    test(1); // swap
    test(2); // std::move
}
```

### Задание 7

Объяснить работу программы Python со строками `a`, `b` и функцией `id`.

#### Решение

Сначала создаётся строковый объект `'Hello world'`, а имя `a` получает ссылку на него. Присваивание `b = a` не копирует строку: оба имени указывают на один неизменяемый объект, поэтому `id(a) == id(b)`.

Операция `a += ' and goodbye'` не может изменить строку на месте, потому что строки неизменяемы. Создаётся новая строка, и имя `a` перенаправляется на неё. 
Имя `b` продолжает ссылаться на старую строку. Поэтому после операции значения и идентификаторы `a` и `b` различаются.

`id(obj)` возвращает уникальный идентификатор объекта на время его жизни. В CPython он обычно совпадает с адресом объекта, но полагаться на это как на переносимое свойство Python нельзя.

**Код Python (задание 7):**

```python
a = 'Hello world'
print(a, id(a))
b = a
print(b, id(b))
a += ' and goodbye'
print(a, id(a))
print(b, id(b))
```

### Задание 8

Есть ли разница для строки между `b = a` и `b = a[:]`?

#### Решение

По значению и поведению программы разницы нет: в обоих случаях `b == a`. Строки неизменяемы, поэтому создавать копию для полной строки не требуется. 
Более того, CPython обычно оптимизирует полный срез и возвращает тот же объект, так что `b is a` также часто истинно. Спецификация языка не требует совпадения идентификаторов, поэтому корректный код не должен зависеть от результата `is` в этом случае.

Пример выше демонстрирует равенство значений и отдельно выводит идентичность объектов как деталь реализации.

**Код Python (задание 8):**

```python
a = 'Hello world'
b = a
print('Присваивание:', a == b, a is b)

b = a[:]
print('Полный срез:', a == b, a is b)
print('id(a):', id(a), 'id(b):', id(b))
```

### Задание 9 **(2)**

Создать 2600 переменных с именами `a0`...`z99` и различными значениями от 1 до 2600.

#### Решение

Имена строятся из буквы и числа и добавляются в глобальное пространство имён через словарь `globals()`:

```python
value = 1
for letter in "abcdefghijklmnopqrstuvwxyz":
    for index in range(100):
        globals()[f"{letter}{index}"] = value
        value += 1

print(a0, a99, b0, z99)  # 1 100 101 2600
```

После выполнения `a0 == 1`, `a99 == 100`, `b0 == 101`, `z99 == 2600`. Для прикладной программы список или словарь был бы удобнее, но задание специально требует динамического создания имён.
