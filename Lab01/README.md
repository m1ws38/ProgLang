# Глоссарий

### Прагматика
Отвечает на вопрос: "Что я хочу получить?". Описывает назначение программы и результат, который требуется получить.

### Семантика
Отвечает на вопрос: "Как это будет работать?". Определяет смысл конструкций языка программирования и правила их выполнения.

### Синтаксис
Отвечает на вопрос: "Как мне это написать?". Определяет правила записи конструкций языка программирования.

### Язык программирования низкого уровня
Язык, на котором можно непосредственно написать программу, исполняемую на физическом устройстве.

### Исполняемый файл
Файл, содержащий программу в виде набора элементарных инструкций, которая после загрузки в память может быть выполнена процессором под управлением операционной системы.

### Ассемблер
Язык программирования низкого уровня, в котором инструкции физического устройства представлены в текстовом виде.

### Язык программирования высокого уровня
Язык, абстрагирующийся от элементарных команд процессора и позволяющий использовать более высокоуровневые понятия: функции, алгоритмы, классы, структуры данных и т.д.

### Исходный код
Текст программы, написанный на языке программирования высокого уровня.

### Виртуальная машина
Средство описания семантики языка программирования. Определяет правила выполнения конструкций языка и поведение программы при нарушении этих правил.

### Стандарт языка программирования
Документ, максимально подробно и формально описывающий язык программирования.

### Транслятор
Программа, осуществляющая перевод текста программы с одного языка на другой.

### Компилятор
Транслятор, переводящий программу в машинный код для последующего исполнения.

### Интерпретатор
Транслятор, читающий и выполняющий программу по отдельным командам.

### Псевдокомпилятор
Транслятор, переводящий программу в промежуточное представление — байт-код.

### Байт-код
Промежуточное представление программы, состоящее из инструкций, близких по смыслу к машинному коду и выполняемых виртуальной машиной.

### Компилирующий интерпретатор
Транслятор, который после запуска переводит программу во внутреннее представление, после чего выполняет уже это внутреннее представление.

### REPL
Read-Eval-Print Loop — цикл «чтение — вычисление — вывод». Интерпретатор получает конструкцию языка, выполняет её и сразу выводит результат.

### Единица трансляции
Минимальный фрагмент программы, который может быть транслирован независимо от остального кода.

### Предобработка
Начальный этап трансляции, во время которого выполняются преобразования исходного текста программы по заданным правилам.

### Синтаксический анализ
Проверка правильности синтаксиса программы перед генерацией кода.

### Оптимизация кода
Преобразование программы с целью улучшения создаваемого машинного кода без изменения результата работы программы.

### Сборка / связывание
Объединение отдельных единиц трансляции и библиотек в одну исполняемую программу.

### Загрузка
Помещение программы в память перед её выполнением.

### Ошибка времени выполнения
Ошибка, обнаруживаемая непосредственно во время выполнения программы, например деление на ноль.

### Непредсказуемое поведение
Ситуация, при которой ошибка может проявиться позднее, в непредсказуемый момент и непредсказуемым способом.

### Неопределённое поведение
Поведение программы, которое не определено стандартом языка и поэтому может различаться в разных реализациях или компиляторах.

### Препроцессинг
Предобработка исходного текста программы до синтаксического анализа.

### '#include'
Директива препроцессора C++, используемая для подключения содержимого другого файла.

### '#pragma'
Директива препроцессора для задания параметров трансляции. Возможности '#pragma' зависят от используемого компилятора.

### '#define'
Директива, позволяющая создать макрос и заменить его имя указанным текстом.

### Условная трансляция
Управление тем, какие фрагменты исходного текста попадут в программу. Для этого используются директивы '#ifdef', '#ifndef', '#else', '#endif'.

### Объектный файл
Промежуточный файл между исходным текстом программы и исполняемым файлом. Код в нём уже транслирован, но отдельные единицы программы ещё не связаны между собой.

### make
Утилита управления процессом компиляции и сборки программы.

### makefile
Файл с описанием целей, зависимостей и команд, которые должна выполнять утилита 'make'.

### JVM
Java Virtual Machine — виртуальная машина, выполняющая Java-байт-код.

### Дизассемблирование
Преобразование скомпилированного кода или байт-кода в текстовое представление инструкций.
